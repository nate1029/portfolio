Impulse IDE

Most hardware IDEs treat AI as an afterthought. Impulse is built the other way around — an AI agent sits at the core, bridging the gap between your code and the hardware directly. Compile, upload, and serial monitor in one place, with an error-memory system that learns from past failures. I built it because my own projects kept getting slowed down by tools that weren’t built for this.

Open source · error-memory cuts repeat debug cycles to zero

Smart Yoga Mat

Yoga apps want you staring at a screen, which defeats the point. This one watches instead: pose estimation tracks your body, compares it against the correct posture, and tells you what to fix in real time — so the phone stays out of the practice. Built custom hardware with an ESP32-CAM module as the vision input, so the whole thing runs standalone.

Smart SOS Helmet

A crash-detection helmet with a companion app that handles GPS and emergency calls. MPU6050 reads the impact; a buzzer fires for 5 seconds giving the rider a pushbutton window to cancel a false alarm — if no one presses it, the ESP confirms the crash and sends SOS automatically. A hard hat for genuinely hard problems, and exactly why Impulse exists.
